# Mac Mini (M2, 2023) - Open 3D Model

A free, accurate 3D model of the 2023 Apple Mac Mini with the M2 chip.

**[Download the model](https://github.com/RameezMilk/mac-mini-m2-2023/releases/download/v1.0/mac-mini-m2-2023.glb)** (.glb, 256 KB)

Opens in Blender, Unity, Unreal, three.js, Windows 3D Viewer, and any app that supports glTF.

## Details

- True to scale: 197 × 197 × 35.8 mm
- Every rear port modeled: Thunderbolt 4 (×2), USB-A (×2), HDMI, Ethernet, headphone jack, power
- Each part is a separate, named object
- Lightweight: about 5,300 triangles, no textures

## Files

| File | Contents |
|---|---|
| `mac-mini-m2-2023.glb` | The model |
| `unity/` | Editable Unity prefab and the script that builds it |
| `index.html` | Simple web viewer |
